================================================================
Terra 语言详细手册
================================================================

Terra（大地）是 SproutOS 的官方专属中文编程语言。它的语法
完全中文、类似易语言，用来开发 SproutOS 自己的软件格式
「.seed 种子包」。代码像种子一样长在大地上，经「耕耘机
terrac」翻成机器能懂的字节码，再由「播种机 Planter」种进系统。


----------------------------------------------------------------
一、命名隐喻
----------------------------------------------------------------

  层级            命名              角色比喻
  --------------- ----------------- ----------------------------------
  编程语言        Terra             大地（代码长在土里）
  编译器          terrac            耕耘机（把代码翻成机器能懂的）
  字节码运行时    SeedVM            种子虚拟机（解释执行 .seed）
  包格式          .seed             种子
  包管理器        Planter           播种机
  软件仓库        The Greenhouse    温室（所有种子存放的地方）


----------------------------------------------------------------
二、工具链
----------------------------------------------------------------

  scripts/terrac.py        Terra 编译器：.terra 源文件 → .seed 包
  scripts/seedvm_test.py   主机端字节码模拟器（调试用，不依赖 OS）
  kernel/seedvm.c          SeedVM 字节码解释器（OS 内核内运行时）
  kernel/seedvm.h          .seed 格式定义 / 操作码 / VM 状态结构
  docs/terra.md            项目内 Markdown 版本文档

Terra 源码以 `.terra` 为后缀，例如 hello.terra。
编译产物是 `.seed` 包，存进磁盘的 /GREENHOU（温室）与
/APPS（花园）目录。


----------------------------------------------------------------
三、编译方式
----------------------------------------------------------------

【方式一：在宿主机用 terrac 研磨（grind）】

  python3 scripts/terrac.py <源文件.terra> -o <输出.seed> -n <包名> -a <作者>

参数说明：
  input        （必填）.terra 源文件路径
  -o/--output  输出 .seed 路径；省略时默认输出到当前目录、取源文件名
  -n/--name    包名（写入 .seed 头的 32 字节字段）；省略时取文件名
  -a/--author  作者名（写入 .seed 头的 32 字节字段）；默认 "SproutOS"

示例：
  python3 scripts/terrac.py hello.terra -o hello.seed -n hello -a SproutOS
  python3 scripts/terrac.py calc.terra  -o calc.seed  -n calc  -a SproutOS

【方式二：随镜像自动打包】

  make_disk.sh 会在构建 disk.img 时，自动用 terrac 把
  scripts/seed-examples/*.terra 编译成 8.3 名 .SEED（如 HELLO.SEED），
  同时放进 /GREENHOU 与 /APPS，所以系统开箱即可 garden / terra run。

【在 SproutOS 内运行】

  进入桌面 → 打开终端 →
    terra run hello        # 运行，运行中按 ESC 退出
    garden                 # 查看已安装包

【在宿主机用模拟器验证（无需 OS / QEMU）】

  python3 scripts/seedvm_test.py hello.seed          # 运行并输出
  python3 scripts/seedvm_test.py hello.seed -t       # 带逐条 trace


----------------------------------------------------------------
四、完整语法
----------------------------------------------------------------

1) 注释
   // 单行注释（两个斜杠开头，到行尾）

2) 输出（打印到屏幕 / 终端）
   输出("文本")
   输出(数字)
   输出("a" + 到文本(b))          // 字符串拼接用 +，数字需先 到文本()
   输出() 换行效果由换行符决定；连续输出会依次打印。

3) 变量
   变量 名字 为 初值        // 声明并初始化
   名字 = 新值              // 赋值（名字须先声明）
   变量名可以是中文，例如：变量 当前 为 1

4) 数据类型
   - 整数：如 0、42、-7、200（范围 32 位有符号）
   - 字符串：双引号包裹，如 "你好"；字符串以堆地址形式存在，
     SeedVM 的 输出 会自动区分整数与字符串。

5) 运算符

   算术：  +  加      -  减      *  乘      /  整除     %  取余
           一元 -  取负（如 变量 x 为 -5；或 输出(-a)）
   比较：  小于  大于  等于  不等于  小于等于  大于等于
           （也可用符号 <  >  ==  !=  <=  >=）
   逻辑：  且  或  非   （等价于 &&  ||  !；非 为一元前缀）

   运算优先级：括号最高，其次 非/一元负，再 乘/除/取余，
   再 加/减，再 比较，最后 且/或。建议多用括号让意图清晰。

6) 条件
   如果 <条件> 则
       ...            // 条件为真时执行
   否则              // 可选
       ...            // 条件为假时执行
   结束

   例：
   如果 a 小于 b 则
       输出("a 更小")
   否则
       输出("b 更小")
   结束

7) 循环

   (a) 计数循环（含端点，步长默认 1）：
       循环 从 <起> 到 <止>
           输出(循环变量)
       结束循环
       循环 从 0 到 100 步 25        // 带步长
       循环变量 是当前迭代的值（1..N 或 起..止，按步长）。

   (b) 当型循环：
       循环 当 <条件>
           ...
       结束循环
       例：循环 当 x 大于 0  →  x = x - 1  →  结束循环

   嵌套循环：每一层循环使用独立的内部变量槽，循环变量互不
   干扰，可安全嵌套。

8) 内置函数

   到文本(整数)       整数 → 字符串（用于拼接 / 输出数字）
   到整数(字符串)     字符串 → 整数
   取宽()             返回屏幕宽度（像素）
   取高()             返回屏幕高度（像素）

9) GUI 绘图（仅当包标记为含 GUI 时才有画面；全屏独占运行）

   清屏()                       清空帧缓冲画布
   刷新()                       把帧缓冲推到屏幕（每次绘制后建议调用）
   画矩形(x, y, 宽, 高, 颜色)   填充矩形（原点左上，坐标向下向右）
   画文字(x, y, "文本", 颜色)   绘制 UTF-8 中文/英文文字
   画圆(x, y, 半径, 颜色)       填充圆
   画线(x1, y1, x2, y2, 颜色)   直线
   画点(x, y, 颜色)             单个像素点

10) 颜色常量（中文颜色名，直接当参数使用）

   黑色  白色  红色  绿色  蓝色  黄色  青色  紫色
   例：画矩形(0, 0, 取宽(), 取高(), 黑色)

五、完整示例源码
----------------------------------------------------------------

下面三个示例均位于 scripts/seed-examples/，已随镜像预装。
可直接阅读、修改后用 terrac 重新编译。

--------------- hello.terra（基础语法） ---------------
// hello.terra — Terra Hello World
// 编译: python3 scripts/terrac.py scripts/seed-examples/hello.terra

输出("你好，SproutOS！")
输出("这是用Terra写的第一个程序")
输出("")

// 变量和运算
变量 a 为 10
变量 b 为 20
输出("a + b = " + 到文本(a + b))
输出("a * b = " + 到文本(a * b))

// 条件判断
如果 a 小于 b 则
    输出("a 小于 b")
否则
    输出("a 不小于 b")
结束

// 计数循环
输出("数数：")
循环 从 1 到 5
    输出("第 " + 到文本(循环变量) + " 次")
结束循环

输出("done!")
-----------------------------------------------

-------------- calc.terra（计算 / 循环 / 嵌套） --------------
// calc.terra — Terra计算器
// 输出平方表、斐波那契数列和质数

输出("=== 平方表 ===")
循环 从 1 到 9
    输出(到文本(循环变量) + " x " + 到文本(循环变量) + " = " + 到文本(循环变量 * 循环变量))
结束循环

输出("")
输出("=== 斐波那契数列 ===")
变量 前项 为 0
变量 当前 为 1
循环 从 1 到 15
    输出("F(" + 到文本(循环变量) + ") = " + 到文本(当前))
    变量 下一项 为 前项 + 当前
    前项 = 当前
    当前 = 下一项
结束循环

输出("")
输出("=== 质数检测 ===")
循环 从 2 到 30
    变量 n 为 循环变量
    变量 是质数 为 1
    变量 除数 为 2
    循环 当 除数 * 除数 小于等于 n
        如果 n % 除数 等于 0 则
            是质数 = 0
        结束
        除数 = 除数 + 1
    结束循环
    如果 是质数 等于 1 则
        输出(到文本(n) + " 是质数")
    结束
结束循环

输出("")
输出("calc done!")

----------------------------------------------------------------
六、.seed 包格式（二进制布局）
----------------------------------------------------------------

.seed 是一个 88 字节头 + 代码段 + 数据段的二进制包。
FAT32 上以 8.3 名存储（如 HELLO.SEED）。

  偏移   大小   字段
  ------ ------ --------------------------------------------------
  0      4      魔数 "SEED"（小端 0x44454553）
  4      2      版本（=1）
  6      2      标志（bit0 = 含 GUI）
  8      32     包名（UTF-8，\0 结尾）
  40     32     作者（UTF-8，\0 结尾）
  72     4      代码段大小（字节）
  76     4      数据段大小（字节）
  80     4      入口偏移（相对代码段起点）
  84     4      保留
  88     ...    代码段（SeedVM 字节码）
  88+cs  ...    数据段（UTF-8 字符串池，\0 分隔）

编译时 terrac 会：
  - 把源码里所有字符串收集进数据段字符串池；
  - 生成从入口开始的字节码写入代码段；
  - 填好 88 字节头（魔数 / 版本 / 标志含 GUI 与否 / 包名 / 作者）。


----------------------------------------------------------------
七、SeedVM 架构（运行时）
----------------------------------------------------------------

SeedVM 是内核里的栈式字节码解释器：

  - 操作数栈：256 深，32 位整数
  - 局部变量：64 个槽
  - 帧制执行：每帧最多执行 2000 条指令，不阻塞主循环，
    保证系统响应（GUI、鼠标等仍可用）
  - 运行时类型检测：遇到"打印"时，若值是堆地址(≥0x1000000)
    则按字符串渲染，否则按整数渲染
  - 全屏独占：运行 .seed 包时进入全屏（类似浏览器），
    按 ESC 退出并清屏回桌面
  - 操作码约 40 个：栈操作、算术、比较、逻辑、跳转、
    变量读写、打印、类型转换、字符串拼接，以及一组 GUI
    指令（清屏/刷新/矩形/文字/圆/线/点/取宽/取高/压颜色）


----------------------------------------------------------------
八、Planter 包管理器
----------------------------------------------------------------

系统在磁盘上用三个目录组织软件（大小写无关匹配）：

  /GREENHOU   温室：所有可用种子（编译产物）
  /APPS       花园：已播种（已安装）的包
  /CACHE      缓存：prune 清理目标

命令（均在终端使用；包名可省略 .SEED、不区分大小写）：

  terra run <包名>   运行包（优先 /APPS，否则 /GREENHOU）；ESC 退出
  plant <包名>       播种（安装）：温室 → 花园
  weed <包名>        除草（卸载）：从花园移除
  water <包名>       浇水（更新单个）：用温室最新版覆盖花园
  rain               下雨（全量更新）：给花园所有包浇水
  garden             花园：列出已安装包及大小
  seek <关键词>      在温室按名搜索（大小写不敏感）
  sniff <包名>       查看种子信息（品种/作者/代码大小/是否GUI）
  prune              修剪：清理 /CACHE 里的缓存/依赖文件
  grind <源文件>     研磨：提示如何在宿主机编译 .terra → .seed

典型流程：
  seek my            # 在温室找 myapp
  plant myapp        # 播种（安装）到花园
  terra run myapp    # 运行
  weed myapp         # 不想要了，除草


----------------------------------------------------------------
九、主机端模拟器（调试利器）
----------------------------------------------------------------

scripts/seedvm_test.py 是一个不依赖操作系统的字节码模拟器，
在宿主机直接跑 .seed，便于快速验证逻辑（无需 QEMU 编译内核）。

  python3 scripts/seedvm_test.py hello.seed        # 运行并输出结果
  python3 scripts/seedvm_test.py hello.seed -t     # 逐条指令 trace

它模拟堆地址、运行时类型检测和 GUI 指令（GUI 指令只消耗参数、
不真正绘图），能复现 SeedVM 的执行逻辑。三个内置示例在
模拟器中均验证通过：hello 139 步、calc 2732 步、draw 132 步。


----------------------------------------------------------------
十、语法特性与注意事项
----------------------------------------------------------------

- 中文分词：关键词按"最长匹配"识别。若关键词后紧跟中文字符，
  会被当成更长的标识符的一部分。例如「当前」不会被拆成
  「当」+「前」，而是作为一个整体变量名。因此给变量起名时
  要避免与关键词连写造成歧义。

- 运算符可混用中文与符号：小于/大于/等于/不等于/小于等于/
  大于等于 与 < > == != <= >= 等价；逻辑 且/或/非 与
  && || ! 等价。同一程序里混用也没问题。

- 数字输出必须 到文本：输出(数字) 可以，但拼接字符串时
  输出("x=" + x) 会报错，应写 输出("x=" + 到文本(x))。

- 取负：负数用一元负号表示（如 变量 x 为 -5），或从表达式
  取负（输出(-a)）。字面量本身也能直接写负整数。

- 嵌套循环安全：每层循环内部变量独立，可放心嵌套。

- 步骤上限：单帧执行 2000 条指令（帧制），长程序会分多帧
  跑完，不会卡死系统；正常小程序一帧即可结束。

- 退出：运行中按 ESC 键从全屏退出回桌面。

- 文件名：磁盘上 .seed 以大写 8.3 名存储（HELLO.SEED），
  但终端命令里用小写包名（hello）即可，驱动大小写无关匹配。


----------------------------------------------------------------
十一、动手示例（从零到运行）
----------------------------------------------------------------

1) 写源码（myapp.terra）：
   // myapp.terra
   输出("我的第一个 Terra 程序")
   变量 n 为 5
   循环 从 1 到 n
       输出("第 " + 到文本(循环变量) + " 行")
   结束循环

2) 在宿主机编译：
   python3 scripts/terrac.py myapp.terra -o myapp.seed -n myapp -a me

3) 把 myapp.seed 放进镜像的 /GREENHOU（或重新 make 自动打包）。

4) 在 SproutOS 终端：
   seek my          # 找到 MYAPP.SEED
   plant myapp      # 安装到花园
   terra run myapp  # 运行（ESC 退出）
   garden           # 确认已安装

至此，你已用 Terra 在大地上播下第一颗种子。
