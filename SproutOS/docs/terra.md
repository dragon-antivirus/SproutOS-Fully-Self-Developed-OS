# Terra — SproutOS 专属中文编程语言

Terra（大地）是 SproutOS 的包格式 `.seed` 的官方开发语言，语法全中文，类似易语言。
代码像种子一样「长」在 Terra 上，经耕耘机 `terrac` 翻成机器能懂的字节码，再用播种机
Planter 种进系统。

## 命名隐喻

| 层级 | 命名 | 角色比喻 |
|------|------|----------|
| 操作系统 | SproutOS | 嫩芽本身 |
| 编程语言 | Terra | 大地（代码长在土里） |
| 语言编译器 | terrac | 耕耘机（把代码翻成机器能懂的） |
| 包管理器 | Planter | 播种机 |
| 安装包后缀 | `.seed` | 种子 |
| 软件仓库 | The Greenhouse | 温室（所有种子存放的地方） |

## 工具链

| 工具 | 说明 |
|------|------|
| `scripts/terrac.py` | Terra 编译器（`.terra` → `.seed`） |
| `scripts/seedvm_test.py` | 主机端字节码模拟器（调试用） |
| `kernel/seedvm.c` | SeedVM 字节码解释器（OS 内运行时） |
| 终端 Planter 命令 | 包管理（见下文） |

## 快速上手

```
// hello.terra
输出("你好，SproutOS！")
变量 x 为 42
输出("x = " + 到文本(x))
```

```bash
# 在宿主机编译（研磨 / grind）
python3 scripts/terrac.py hello.terra -o hello.seed -n hello -a SproutOS

# 在 SproutOS 终端运行
terra run hello
```

## 语法

### 输出

```
输出("文本")
输出(数字)
输出("a" + 到文本(b))
```

### 变量

```
变量 名字 为 初值       // 声明
名字 = 新值              // 赋值
```

### 条件

```
如果 x 小于 y 则
    输出("x 更小")
否则
    输出("y 更小")
结束
```

比较运算：`小于` `大于` `等于` `不等于` `小于等于` `大于等于`（也可用 `<` `>` `==` `!=` `<=` `>=`）

逻辑运算：`且` `或` `非`

### 循环

```
// 计数循环（含端点）
循环 从 1 到 10
    输出(循环变量)
结束循环

// 步长
循环 从 0 到 100 步 25
    输出(循环变量)
结束循环

// 当型循环
循环 当 x 大于 0
    x = x - 1
结束循环
```


## .seed 包格式

```
偏移   大小   字段
0      4     魔数 "SEED" (0x44454553)
4      2     版本 (=1)
6      2     标志 (bit0=含GUI)
8      32    包名 (UTF-8, \0 结尾)
40     32    作者 (UTF-8, \0 结尾)
72     4     代码段大小
76     4     数据段大小
80     4     入口偏移
84     4     保留
88     ...   代码段（字节码）
88+cs  ...   数据段（UTF-8 字符串池, \0 分隔）
```

## SeedVM 架构

栈式字节码机：
- 256 深操作数栈（32 位）
- 64 个局部变量槽
- 帧制执行（每帧 2000 条指令，不阻塞主循环）
- 运行时类型检测：堆地址(≥0x1000000)→字符串，小整数→数字
- ESC 键退出回桌面

## Planter 包管理器

系统在磁盘上用三个目录组织软件（FAT32 8.3 名）：

| 目录 | 含义 |
|------|------|
| `/GREENHOU` | The Greenhouse（温室）：所有可用种子 |
| `/APPS` | 花园：已播种（已安装）的包 |
| `/CACHE` | 缓存/依赖：prune 清理目标 |

> 注：`make_disk.sh` 会把 `scripts/seed-examples/*.terra` 编译后同时放进温室和花园，
> 所以系统开箱即可 `garden` / `terra run`。

| 命令 | 含义 | 说明 |
|------|------|------|
| `terra run <包名>` | 运行包 | 优先从花园(/APPS)找，否则从温室(/GREENHOU)找；ESC 退出 |
| `plant <包名>` | 播种(安装) | 把种子从温室复制到花园 |
| `weed <包名>` | 除草(卸载) | 从花园移除 |
| `water <包名>` | 浇水(更新单个) | 从温室重新复制到花园（覆盖） |
| `rain` | 下雨(全量更新) | 给花园里所有包浇水 |
| `garden` | 花园 | 列出已安装（花园）的包 |
| `seek <关键词>` | 找种子 | 在温室里按名搜索（大小写不敏感） |
| `sniff <包名>` | 闻一闻 | 查看种子信息（品种/作者/代码大小/GUI） |
| `prune` | 修剪 | 清理缓存/依赖目录 |
| `grind <源文件>` | 研磨 | 在宿主机把 `.terra` 编译成 `.seed`（系统内有用法提示） |
| `planter` | 帮助 | 列出上述所有包管理命令 |

包名不区分大小写、可省略 `.SEED` 后缀（如 `terra run hello` 等价于 `terra run HELLO.SEED`）。

### 典型流程

```bash
# 1) 在宿主机写源码并用 terrac 研磨成 .seed
python3 scripts/terrac.py myapp.terra -o myapp.seed -n myapp -a me

# 2) 把 myapp.seed 放进镜像的 /GREENHOU（或编译时自动打包）

# 3) 在 SproutOS 终端
seek my            # 在温室找 myapp
plant myapp        # 播种（安装）到花园
terra run myapp    # 运行
weed myapp         # 不想要了，除草
```

## 易语言风格语法（2026-08-20 新增）
为了写起来不切输入法，Terra 在保留原语法的同时加入了易语言风格写法，编译器把全角符号自动转成半角。两种写法等价可混用。

| 原写法 | 易语言风格 |
|---|---|
| `变量 名 为 值` | `新建变量 名`（默认 0）  +  `名 = 值` 赋值 |
| `如果 条件 则 … 否则 … 结束` | `如果 (条件) … 否则 … 如果结束` |
| `循环 从 A 到 B [步 S] … 结束循环` | `计次循环首 (N, 计数变量) … 计次循环尾 ()` |
| `循环 当 条件 … 结束循环` | `判断循环首 (条件) … 判断循环尾 ()` |

### 全角→半角自动转换
编译器在 `tokenize` 开头调用 `normalize_src()`，识别以下全角/中文标点直接当半角用：

| 全角 | 变 | 用途 |
|---|---|---|
| `（）` `，` `""` `''` `；` `：` `？` `＋` `－` `＊` `／` `％` `＝` `＜` `＞` `！` | 半角 ASCII | FF01–FF5E 范围自动映射 |
| `“` `”` `‘` `’` | `"` `'` | 中文引号 |
| `、` | `,` | 顿号（列表分隔） |
| `≤` `≥` `≠` | `<=` `>=` `!=` | 数学比较 |
| `【】` | `[]` | 中文方括号 |
| `。` | `.` | 句号（防误报） |

IDE（`seed-ide/SproutOS_Seed_IDE.exe`）默认开启**智能符号**：输入时全角→半角自动转，写代码不用切输入法。

## Seed IDE 开发平台
面向 Windows 的 Terra 开发环境，VSCode 风格深色界面、Terra 中文语法高亮、行号、文件树、`编译/运行/调试` 一键。

- 源码开发：`seed-ide/app.py` + `web/` + `run.bat`（需 Python 3.8+）
- **正式交付：`seed-ide/SproutOS_Seed_IDE.exe`（单文件 8 MB，PyInstaller --onefile 冻结，自带 Python 解释器，双击即用，无需 Python 环境）**
- 启动：双击 exe → 自动开浏览器 → `http://localhost:8000`
- 工作区：exe 同目录的 `workspace/`
- 资源：terrac / SeedVM / web / seed-examples 全部内置

构建 exe（开发者用）：
```bash
pyinstaller --noconfirm --onefile --clean \
  --name SproutOS_Seed_IDE \
  --add-data "../scripts;scripts" --add-data "web;web" app.py
```

新示例：`scripts/seed-examples/epl_demo.terra`（用全角符号演示易语言风格）。

## 当前语法（2026-08-20 最终版：已移除旧语法）

**旧语法（`变量…为`、`如果…则…结束`、`循环 从/当…结束循环`、`循环变量`）已全部移除**，只保留易语言风格：

| 语句 | 写法 |
|---|---|
| 变量声明 | `新建变量 名`（默认 0），赋值 `名 = 值` |
| 条件 | `如果 (条件) … 否则 … 如果结束` |
| 计数循环 | `计数循环 (次数, 计数变量) … 循环结束 ()`（计数 1..次数） |
| 判断循环 | `判断循环 (条件) … 循环结束 ()`（每轮重判条件） |
| 无限循环 | `标准循环 (间隔毫秒, 计数变量) … 循环结束 ()`（计数器从 0 递增） |
| 跳出 | `跳出循环 ()`（仅限循环内，跳出最内层） |

示例：`计数循环 (5, i)` 里 i 依次为 1..5；`标准循环 (100, c)` 每轮休 100ms、c 从 0 递增。

### 交互支持库（交互_输出 / 交互_取终端反馈）

```terra
支持库引入 (交互支持库1.0)
新建变量 次数
交互_输出 ("请输入次数（数字）：", 数字)   // 输出并等待回答；类型错误会重新询问
次数 = 交互_取终端反馈()                   // 取回回答（数字=整数 / 文本=字符串）
计数循环 (次数, i)
    输出("第 " + 到文本(i) + " 次")
循环结束 ()
```

- 回答类型：`文本` / `数字`（`整数` 为 `数字` 别名）。类型不符会提示「（回答类型错误，请重新输入）」并重问。
- IDE 中运行到 `交互_输出` 会弹出输入框；SeedVM 模拟器通过 `input_queue` 喂答案。
- 完整示例见 `scripts/seed-examples/interact.terra`。

### 新字节码操作码

| 操作码 | 值 | 含义 |
|---|---|---|
| OP_SLEEP | 0x91 | pop 毫秒，忙等（内核 `udelay`；主机 `time.sleep`） |
| OP_ASK | 0xA0 | +1字节类型(0=文本,1=数字)；pop 提示串；输出并索取输入，类型错误重问 |
| OP_GETINPUT | 0xA1 | 压入最近一次 OP_ASK 的答案 |

> 内核 `kernel/seedvm.c` 的 OP_ASK 无真实键盘输入，会打印提示后返回空值（IDE/主机模拟器才支持完整交互）；OP_SLEEP 内核为忙等，注意帧内阻塞。
