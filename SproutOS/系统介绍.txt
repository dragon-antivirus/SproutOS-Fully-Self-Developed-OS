================================================================
SproutOS 系统介绍
================================================================

SproutOS（嫩芽操作系统）是一个从零自研的、教学与趣味导向的
x86 操作系统。它拥有图形桌面、中文界面、文件管理、文本编辑、
画图、网络浏览，以及一整套「中文编程语言 + 字节码虚拟机 +
包管理器」的软件生态。整个系统围绕一个温柔的隐喻展开：
代码像种子一样种在「大地(Terra)」上，再用「播种机(Planter)」
种进系统，长成应用。


----------------------------------------------------------------
一、设计哲学与命名隐喻
----------------------------------------------------------------

SproutOS 把"种植"作为贯穿全系统的核心隐喻，每一层都有对应的
角色名：

  层级            命名              角色比喻
  --------------- ----------------- ----------------------------------
  操作系统        SproutOS          嫩芽本身
  编程语言        Terra             大地（代码长在土里）
  语言编译器      terrac            耕耘机（把代码翻成机器能懂的）
  包管理器        Planter           播种机
  安装包后缀      .seed             种子
  软件仓库        The Greenhouse    温室（所有种子存放的地方）
  已安装目录      /APPS             花园（种下去、长出来的应用）
  缓存/依赖目录   /CACHE            待修剪的枯枝烂叶

这种命名让"写程序→编译→安装→运行→卸载"的过程，变成
"耕耘→播种→浇水→收获→除草"，直观且贴合操作系统教学场景。


----------------------------------------------------------------
二、启动与硬件
----------------------------------------------------------------

- 启动方式：同时支持 BIOS（传统）与 UEFI 启动。内核零改动，
  靠 multiboot1 头兼容两种固件；构建时会生成混合 ISO，
  其中包含 ESP/BOOTX64.EFI。
- 启动徽章：进入桌面后，屏幕右上角会显示一枚药丸状徽章，
  标明当前是「BIOS」还是「UEFI」启动，便于区分运行环境。
- 开机动画：不再是静态 Logo，而是 SproutOS 字形的"书写"
  动画——先逐列写出白色的大"S"，滑到左侧，再同时写出
  "prout"，最后右侧出现一个光点，分裂成两个并渐变成蓝色，
  最终拼出蓝色的 "SproutOS"。

运行环境：x86（32 位），通过 QEMU 模拟器运行；网卡使用
e1000 / rtl8139 虚拟网卡。


----------------------------------------------------------------
三、图形桌面
----------------------------------------------------------------

桌面是一套自研的窗口管理器与图标系统：

- 桌面图标：彩色圆角方块 + 下方白色中文标签，竖向排列。
  默认图标：文件管理、回收站、终端、画图、浏览器、关于。
- 窗口：标题栏可拖动、可关闭；标题栏中文标签。
- 任务栏 / 开始菜单：均为中文。
- 中文字体：运行时加载 TTF 字体（stb_truetype 栅格化），
  支持 UTF-8 中文直接渲染；窗口标题等走中文渲染通道，
  窗口内部 ASCII 内容走点阵字库。

图形能力由帧缓冲（framebuffer）驱动，支持全屏独占应用
（浏览器、Terra 程序均以此方式运行）。


----------------------------------------------------------------
四、内置应用
----------------------------------------------------------------

1. 文件管理（Files）
   - 浏览 FAT32 磁盘目录，图标 + 中文名展示。
   - 右键文件：打开 / 复制 / 剪切 / 设为壁纸 / 删除 / 重命名。
   - 右键空白处：新建文件夹 / 粘贴。
   - 删除并非真正删除，而是移入回收站目录 /RECYCLE，可还原。

2. 文本编辑器（Editor）
   - 简单的文本编辑，支持中文输入与保存，可自定义保存文件名。

3. 终端（Terminal）
   - 命令行界面，支持全部命令行（见第六节）。
   - 是运行 Terra 程序、管理软件包、调试网络的主入口。

4. 画图（Paint）
   - 简易绘图应用。

5. 浏览器（Browser）
   - 全屏网页浏览，自研极简 HTML 引擎（容错解析）。

   已实现的能力：
   - 上网：地址栏输入 `http://站点` 直接抓取并渲染（如
     `http://example.com` 已实测成功加载）。
   - 搜索：地址栏输入纯关键词（不带 http://）自动当搜索词，
     内置 6 个引擎可选（百度/必应/谷歌/搜狗/360 搜索/DuckDuckGo），
     默认百度，偏好存于 `/browser/srchcfg.txt`。
   - 浏览：后退/前进（64 条历史）、刷新、回主页、关闭；
     点击页面里 `<a>` 链接跳转（蓝色、悬停变红、状态栏显示目标）；
     鼠标点滚动条 + 方向键上下左右滚动。
   - 本地文件：地址栏输入 `/` 开头路径（如 `/browser/home.html`）
     从 FAT32 磁盘读取渲染；本地 `<img>` 支持 24/32 位 BMP。

   HTML 渲染范围（自研解析器）：
   - 块级：div / p / h1–h6 / blockquote / center / ul / ol / li /
     hr / pre
   - 行内：b / strong（加粗）、small / sup / sub、br 换行
   - 样式：color / background-color / font-size / text-align /
     font-weight / line-height / margin（颜色支持英文名与
     #rgb / #rrggbb）；中文/英文 UTF-8 混排。

   当前的边界（诚实说明）：
   - 没有 JavaScript：<script> 整个被跳过，动态页面/SPA/登录/
     搜索联想只能拿到初始静态 HTML。
   - 没有 HTTPS/TLS：真实安全站点打不开（直连 https:// 名义支持
     但内核无 TLS，内容取不到）。
   - 没有远程图片/外部 CSS：外链图片显示灰框"图"占位，仅本地
     BMP 能显示。
   - 没有表单交互：<input> 不渲染，搜索框/登录框不可用（搜索靠
     地址栏关键词实现）。
   - 单窗口单页，无标签页；HTML 解析器为教学级容错，复杂/不规范
     页面可能错位。

   一句话：它是能跑通 HTTP、渲染静态中文网页、带搜索与超链接
   跳转的极简浏览器，教学演示和看简单页面够用；离"真上网冲浪"
   还差 TLS + JS 两大件。

   推荐测试站点（实测可正常加载）：
   - http://example.com       标准测试页，200 OK，最干净的演示
   - http://neverssl.com      专为无 TLS 测试而生，绝不跳 https
   说明：浏览器无站点白名单，任何明文 http:// 站点都能进；但
   大站（百度/必应/谷歌/搜狗/360 等）几乎都强制跳 https，直连
   http:// 会被 302 走掉而拿不到内容；纯 JS 动态页（如百度首页）
   会渲染成空白。

6. 关于（About）
   - 系统信息展示窗口。

7. 回收站（Recycle）
   - 被"删除"的文件统一存放在 /RECYCLE（8.3 名），
     可通过文件管理还原或彻底清除。


----------------------------------------------------------------
五、文件系统
----------------------------------------------------------------

- 文件系统类型：FAT32（自研驱动，8.3 短文件名 + 可选长文件名）。
- 文件名匹配大小写无关：终端里打 hello.SEED 与 HELLO.SEED 等价。
- 回收站机制：删除 = 移入 /RECYCLE；提供还原（restore）与
  彻底删除（purge）。
- 复制 / 剪切 / 粘贴：剪贴板记录源目录与文件名，跨目录拷贝。
- 包管理三目录（见第七节）：/GREENHOU（温室）、/APPS（花园）、
  /CACHE（缓存）。


----------------------------------------------------------------
六、全部命令行
----------------------------------------------------------------

SproutOS 的命令行集中在「终端」应用中。命令不区分大小写
（由命令解析层统一处理），包名可省略 .SEED 后缀、且不区分大小写。

【通用命令】

  命令                 说明
  -------------------  --------------------------------------------------
  help                 显示所有命令的简要列表
  ls [目录]            列出当前目录内容（目录名后带 "/"）
  pwd                  显示当前工作目录路径
  cd <目录>            切换目录：cd / 或 cd（空）回到根目录；
                       cd .. 返回上一级；cd <名> 进入子目录
  cat <文件>           打印文本文件内容
  echo <文本>          回显一行文本
  date                 显示 RTC 实时时钟日期时间（YYYY-MM-DD HH:MM）
  clear                清屏
  ver                  显示系统版本（SproutOS v1.0）

【网络命令】（M4）

  net                  显示网络状态（驱动名、MAC、IP、网关、掩码、
                       是否已连接），并触发一次 ARP 解析
  net status / info    同上，显式查看网络状态
  net gw <IP>          设置网关 IP（跨网段通信必须正确配置网关）
  net mask <IP>        设置子网掩码
  ping <IP>            发送 ICMP 回声请求（user 模式下可能被 slirp
                       过滤，TCP/DNS 仍正常）

  说明：默认网关 10.0.2.2（/24）。若用 VMware NAT，网关并非
  10.0.2.2，需用 `net gw` 设为实际网关，否则跨网段（公网）
  数据包发不出去。

【Terra 运行与 Planter 包管理】（M5）

  命令                 说明
  -------------------  --------------------------------------------------
  terra run <包名>     运行一个 .seed 包（优先从花园 /APPS 找，
                       否则从温室 /GREENHOU 找）；运行中按 ESC 退出
  terra help           显示 Terra 运行时帮助
  planter              列出下面所有包管理命令（中文帮助）
  plant <包名>         播种（安装）：从温室复制到花园
  weed <包名>          除草（卸载）：从花园移除
  water <包名>         浇水（更新单个）：用温室里的最新版本覆盖花园
  rain                 下雨（全量更新）：给花园里所有包浇水
  garden               花园：列出已安装（花园）的所有包及大小
  seek <关键词>        在温室里按名搜索种子（大小写不敏感）
  sniff <包名>         闻一闻：查看种子信息（品种/作者/代码大小/是否GUI）
  prune                修剪：清理缓存/依赖目录（/CACHE）里的文件
  grind <源文件>       研磨：提示如何在宿主机把 .terra 编译成 .seed
                       （系统内有用法示例；实际编译在宿主机完成）

  包名示例：terra run hello 等价于 terra run HELLO.SEED。
  典型流程：seek my → plant myapp → terra run myapp → weed myapp。


----------------------------------------------------------------
七、软件包与编程语言生态（包管理 M5）
----------------------------------------------------------------

SproutOS 拥有自研的软件格式与中文编程语言：

- Terra（大地）：SproutOS 的官方中文编程语言，语法全中文、
  类似易语言，用中文关键词写程序。
- terrac（耕耘机）：Terra 编译器（scripts/terrac.py），
  把 .terra 源文件编译成 .seed 字节码包。
- .seed（种子）：SproutOS 专属安装包格式（88 字节头 + 代码段
  + 字符串数据段）。
- SeedVM：内核里的栈式字节码解释器，全屏独占运行 .seed 包，
  ESC 退出回桌面。
- Planter（播种机）：包管理器，用 plant/weed/water/rain/garden/
  seek/sniff/prune 等"种植"命令组织软件。

仓库结构（磁盘上）：
  /GREENHOU   温室：所有可用种子（编译产物）
  /APPS       花园：已安装（已播种）的包
  /CACHE      缓存：临时/依赖文件，prune 清理目标

关于 Terra 的语法、编译方式、完整示例与 .seed 二进制布局，
详见随附的《Terra语言手册.txt》。


----------------------------------------------------------------
八、构建与运行
----------------------------------------------------------------

本系统需在无 i386 工具链的宿主机之外构建（项目约定在
Ubuntu 虚拟机中编译）。

构建依赖（Ubuntu / Debian 系，需一次性安装）：

  sudo apt update
  sudo apt install -y build-essential gcc-multilib nasm \
       grub-pc-bin grub-common xorriso qemu-system-x86 mtools \
       grub-efi-amd64-bin ovmf

  依赖说明：
    包名                 作用
    -------------------  --------------------------------------------------
    build-essential     基础编译工具链（gcc / make 等）
    gcc-multilib        32 位（i386）编译支持，内核以 -m32 编译必需
    nasm                汇编 boot.asm / gdt.asm 为 32 位目标文件
    grub-pc-bin         提供 BIOS 启动核心镜像
    grub-common         GRUB 公共文件
    xorriso             grub-mkrescue 生成混合 ISO 所必需
    qemu-system-x86     QEMU 模拟器，用于 make run 启动系统
    mtools              make_disk.sh 打包 FAT32 磁盘镜像（disk.img）
    grub-efi-amd64-bin  让 ISO 内嵌 EFI 启动镜像（UEFI 支持，推荐）
    ovmf                QEMU 的 UEFI 固件，make run-uefi 需要（可选）

  直接执行仓库里的 setup.sh 也会一次性装好以上全部依赖并完成
  编译与启动，无需手动逐条安装。

构建流程：

  make clean          # 清理
  make iso            # 生成混合 ISO（含 UEFI 支持）
  make run            # 用 QEMU 启动（自动 ensure-disk 打包资源）

其他构建目标：
  make run-uefi       # 以 UEFI 方式启动（OVMF）
  make debug-uefi     # UEFI + 调试
  make test-uefi      # UEFI 自测

资源打包：make_disk.sh 自动把字体、壁纸、浏览器资源以及
scripts/seed-examples/*.terra 编译成的 .seed 包打进 disk.img；
ensure-disk 会在源文件（.terra / terrac.py / 字体 / 壁纸 /
浏览器资源）更新时自动重建镜像。

QEMU 启动参数（网卡示例）：
  -netdev user,id=n0 -device e1000,netdev=n0


----------------------------------------------------------------
九、里程碑回顾
----------------------------------------------------------------

  M0～M3   内核与基础外设（内存、中断、键盘、鼠标、帧缓冲）
  M4       网络基础（e1000/rtl8139 + ARP/IP/ICMP/TCP/UDP/DNS/HTTP
           + net / ping 命令）
  M5       包管理（Terra 中文语言 + terrac 编译器 + .seed 格式
           + SeedVM 解释器 + Planter 包管理器 + 温室/花园/缓存）

SproutOS 是一个持续生长的"嫩芽"——每一次功能落地，都是往
大地里播下一颗新的种子。
